## Strengths
- Self-hosted: the plugin runs on your own WordPress site, so you keep and own the data
- One flat license covers unlimited projects, unlimited sites, and unlimited users
- Guests comment with just name and email, no account or login needed
- Private internal comments limited to chosen WordPress user roles (lock icon toggle)
- 1-click client approvals plus page/project approval workflow
- 100% white label; GPL licensed so you can modify the code
- Works on any platform (WordPress, Shopify, Webflow, HTML) via a child plugin or snippet

## Limits
- Nothing checks the site on its own (a person finds every issue via point, click, type). No AI (checked July 2026)
- No memory concept in product; each project starts blank (checked July 2026)
- No native two-way sync with Jira, Trello, or Asana. Automation only through Zapier or Make using WordPress triggers (checked July 2026)
- No video or screen recording feature verified on the self-hosted plugin
- Cloud is a separate paid product; a plugin purchase does not include Cloud
