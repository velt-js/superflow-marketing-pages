# Truth block: Ruttl (verified July 2026, from ruttl.com)

Researched from the vendor's own site only: ruttl.com product, feature, pricing, and support
pages, plus the vendor's own Chrome Web Store listing. Blogs and listicles were not used as fact
sources. Aggregators were rejected. Rules: vendor facts only, dated. Absence of evidence stays a
dash, not a "no". Angle: Ruttl is the closest look-alike to classic website-feedback tools, with a
live-page suggest-edits mode. The honest frame is what it does well.

## Strengths
- Edit mode on the live page. You can visually change text, images, layout, and font, and edit HTML and CSS, without touching code
- Pixel-pinned contextual comments on live websites, plus web apps, mobile apps, images, and PDFs
- Guests comment free from a shareable link, no signup
- Built-in Kanban workflow. Convert comments to tasks, assign owners, set priority and deadlines
- Screen-recorded video comments
- Approve page locks a page so no more comments or edits can be made

## Limits
- Nothing scans the site for bugs on its own. A person finds every issue. Ruttl AI is scoped to comment sentiment analysis and site performance suggestions. Accessibility checks, SEO insights, and codebase audit are marked "Coming soon" (checked July 2026, ruttl.com)
- No memory or knowledge concept found. Versioning keeps old versions with their comments, but that is not a per-client memory (checked July 2026)
- Behind-login and web-app review needs the Ruttl Chrome extension
- Free (Basic) caps are tight: 1 project, 5 pages, 10 comments, 1GB storage

## Pricing (verified July 2026, ruttl.com/pricing)
- Basic: Free. 1 project, 5 pages, all project types, core integrations (Trello, Slack, Asana, Jira), 10 comments, 10 private comments, 1GB storage. Note: the plan card says "Upto 5 users" and "Unlimited Guests" while the comparison table says 1 user and up to 5 guests
- Pro: $18 per month per user (pricing page has a monthly and yearly toggle; captured value shown). 1 admin plus up to 50 users, unlimited projects, pages, and guests, all integrations including ClickUp, versioning, mobile responsiveness, 50GB storage, dedicated success manager, priority support
- Business: Custom, contact sales. Unlimited admins, users, projects, pages, and guests, all integrations, centralised project management, dedicated team workspace, SAML support, 100GB storage
- Enterprise: custom. Run on your custom domain in your brand colours, up to 50 users, unlimited guests, 100+ projects
- Guests are free. No page-view caps advertised

## Stay line
If pixel-pinned commenting plus live-page visual edits on websites, with free guest links and a built-in Kanban, is what your studio needs, Ruttl is a fine tool. Stay.
